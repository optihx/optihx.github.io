        Comment c'est calculé ?

        Persos niveau 90, toutes les compétences niveau 10, arme niveau 90. Les multiplicateurs viennent des données du jeu (version française).

        Échos : build classique 4-3-3-1-1 (Taux ou Dgt CRIT sur le coût 4, la stat conseillée sur les coûts 3, ATQ sur les coûts 1) + set 2 pièces. La qualité des échos règle les substats : correcte ≈ 25 % taux CRIT / 50 % Dgt CRIT, bonne ≈ 35 / 70, excellente ≈ 45 / 90.

        La rotation de base lance chaque compétence une fois (et une combo d'attaques normales). Ouvre la fiche d'un perso pour régler le nombre d'utilisations.

        Pas pris en compte : passifs d'arme, séquences, effets 5 pièces, buffs automatiques de l'Intro et de l'Outro. Ajoute-les à la main dans « Buffs d'équipe ». C'est une estimation pour comparer des teams, pas un chiffre exact du jeu.
